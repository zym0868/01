F-CGPM
This is a demo of the F-CGPM for solving large-scale constrained nonlinear equations

[ F(x)=0,\quad x\in C, ]
where (C) is a nonempty closed convex set.
The proposed algorithm is based on a unified conjugate gradient projection framework with truncation and restart mechanisms, together with a tunable-parameter line search technique. It can also be applied to image restoration and sparse signal recovery.
